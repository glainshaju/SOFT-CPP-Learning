## ▶️ How to Run

**1. Clone this repository**

```bash
git clone https://github.com/glainshaju/SOFT-CPP-Learning.git
```

**2. Open the project folder**

```bash
cd SOFT-CPP-Learning
```

**3. Compile a C++ program**

```bash
g++ -std=c++17 Even_or_Odd.cpp -o program
```

**4. Run the program**

Windows:
```bash
.\program.exe
```

Linux / macOS:
```bash
./program
```

Replace `Even_or_Odd.cpp` with the program you want to execute.
